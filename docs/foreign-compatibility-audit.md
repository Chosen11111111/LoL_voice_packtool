# 外服兼容检查（2026-10-15）

## 发现与修复

| 问题 | 复现条件 | 修复后的行为 |
| --- | --- | --- |
| 替换了错误语种但提示成功 | 韩文等客户端同时安装英文资源，英文文件稍多 | 优先读取该安装的客户端当前语种，不再按数量猜 |
| 读取错误或无效的 locale | 当前配置与子目录旧配置共存，或注释里出现 locale | 当前目录配置优先；共享解析器兼容引号、无引号、CRLF，跳过注释和相似键 |
| 接口语种来源串安装 | 所选安装设置缺失，另一份客户端正在运行；或接口只有无关字段含语种码 | 只查询与所选安装目录一致的运行中客户端，严格读取 JSON 的 locale 字段 |
| 无法识别当前语种仍写英文槽位 | 多语种安装且客户端设置不可读 | 预检和实际切换均停止并说明原因；还原已有备份仍可执行 |
| Riot 游戏目录定位错误 | 自身和上一级同时存在 Game 目录 | 先找本安装的 Game，再兼容分离目录布局 |
| 切外服后立即开启仍用旧区服 | 配置请求尚未落盘就创建任务 | 等待配置写入完成；保存失败时不提交切换任务 |
| 外服大厅还原被改成中文 | 大厅语言曾被切换，或从未被本工具修改 | 首次修改前记录 locale，按原值还原；无记录则不改。保留其他设置变化 |
| 外服原版状态显示国服 | 未切换或还原完成 | 界面、API、还原提示使用“客户端原版” |

修改前工作区干净，备份标签为 `backup/foreign-compatibility-before-fix-20261015`，基线为 `f420e82`。

## 验证范围

语种集合核对于 [Riot Data Dragon 官方语言清单](https://ddragon.leagueoflegends.com/cdn/languages.json)。27 个外服语种和 `zh_CN` 对照，各覆盖 Riot 根目录及 LeagueClient/Game 分离目录，共 56 组。

`tests/foreign-matrix.test.ts` 在临时目录构造多语种安装，实际读写文件，依次开启日语、韩语，再还原：

- 英雄、播报员、游戏文字写入当前客户端语种槽位；
- 切第二个包后，首次原版备份保持不变；
- 其他语种和公共 wad 文件保持原样；
- 还原后逐文件内容一致，备份被清理；
- 当前语种不明时没有任何替换，也不产生备份。

`tests/server.test.ts` 另经真实 HTTP 服务验证韩文、繁中、法文和英文：保存配置 → 查询客户端 → 预检 → 创建任务 → 查询任务结果 → 核对文件 → 默认还原 → 查询状态。

`tests/ui-config.test.ts` 执行实际前端脚本和事件，覆盖区服保存等待、保存失败阻止任务及状态文字；测试使用模拟 DOM，并非可视化浏览器验收。`tests/lobby-lang.test.ts` 覆盖大厅设置兼容与原语种还原。

矩阵使用独立临时目录，避免旧测试助手的全局 suite 和清理钩子干扰并发用例。

## 真实环境边界

本机只读检查确认：实际国服配置位于客户端目录自身的 `Config/LeagueClientSettings.yaml`，当前语种 `zh_CN`；游戏中英文文件各 181 个。新实现按客户端设置识别，不需要平票推断。

没有更改本机真实游戏资源，也没有用真实外服账号逐区进入对局。以上矩阵证明路径、识别、文件替换、备份、还原和接口流程，不能替代各区客户端实际加载及播放验收。
